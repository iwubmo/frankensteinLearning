Troubleshooting

Metahumans

Head is detached from Body when animating in Sequencer

Start by re-exporting the head animation without head movement.

  1. Open the Metahuman Performance Asset for your facial animation.
  2. Process animation if needed.
  3. Click "Export Animation".
  4. Uncheck "Enable Head Movement".

If the problem still persists, try disabling post-processing on the Face and Body:

  1. In the World Outliner, select your Metahuman.
  2. In the Details Panel, select the "Body" component of your Metahuman.
  3. Check "Disable Post Processing".
  4. Repeat steps 2-3 with the "Face" component of your Metahuman.
  5. You may need to try different combinations of having Post Processing enabled and disabled on the "Face" and/or "Body" components.
Metahuman is stretching/warping when animating in Sequencer

Try disabling post-processing on the Face and Body:

  1. In the World Outliner, select your Metahuman.
  2. In the Details Panel, select the "Body" component of your Metahuman.
  3. Check "Disable Post Processing".
  4. Repeat steps 2-3 with the "Face" component of your Metahuman.

Performance

Received a warning about Texture Pool size

In the Unreal Command Line, enter:

r.TextureStreaming = "2000"

NOTE:

  1. The number may need to be greater than 2000 if you have a lot of textures in your level.
  2. This is a temporary fix. The command will need to be run every time you restart your project.
