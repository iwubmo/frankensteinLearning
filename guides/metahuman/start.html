Metahumans - Getting Started

Create a Metahuman with Metahuman Creator and import it into a project

Create a Metahuman

  1. Go to Metahuman Creator, a cloud-based application for creating Metahumans that is accessed via a web browser. If you have not already signed up for Metahuman Creator, you may need to do so before gaining access to the application.

  2. Design your Metahuman! If you would like a video guide on the different tools within Metahuman Creator, I recommend this one from Gorka Games:

Quick Tip

The Metahuman hair and body types you choose can affect what options you have later on for outfits. It can be helpful to have an idea in advance of what clothing assets you plan to use. Don't worry though, if you need to change it later on, you can always re-export your Metahuman

Setup Your Project

  1. Create a project and add the Quixel Bridge plugin if you do not already have a project setup already.

  2. Download the Metahuman Plugin from the Unreal Engine Marketplace and install it to the Unreal Engine version you plan to use.

  3. Open your project and then open Quixel Bridge. Navigate to [Metahumans --> My Metahumans] to see the characters you created in Metahuman Creator.

  4. Select the Metahuman you wish to download and be sure to select your desired download quality in the panel that opens on the right. Then, in that panel, click the download icon. The interface could take a bit to respond, so be patient. Once the download it complete (which can take awhile), click the plus symbol to add your Metahuman to your project.

  5. After your Metahuman has been added, Unreal will likely prompt you to enable missing plugins. Select [Enable]. For more info on required plugins, check out the Official Metahuman Documentation.

  6. Open Project Settings and search for "Caching". Under "IMG Media" apply the following settings:

    • Cache Behind Percentage = 25
    • Cache Size GB = 2
    • Cache Threads = 4
    • Global Cache Size GB = 2
    • Use Global Cache = [checked]
    • Cache Thread Stack Size KB = 128
